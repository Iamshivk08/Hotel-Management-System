# Hotel Booking & Management E-Commerce Platform

Student-level mini project for hotel room search, booking, payment simulation, hotel management, and admin reporting.

## Included

- `frontend/` - HTML5, CSS3, and JavaScript single-page demo
- `backend/` - Spring Boot source skeleton with entities, repositories, services, and controllers
- `database/schema.sql` - MySQL/PostgreSQL-friendly database tables and seed data

## Run Frontend Demo

Open `frontend/index.html` in a browser.

## Run Backend

The backend is a Spring Boot project. With Maven installed:

```bash
cd backend
mvn spring-boot:run
```

Configure the database connection in `backend/src/main/resources/application.properties`.
